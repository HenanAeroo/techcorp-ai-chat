# techcorp-ai-chat

Projet de chat IA — TechCorp.

## Architecture du Projet

```
techcorp-ai-chat/
├── tritton_server/      # Configuration Triton Inference Server
├── models/              # Modèle Phi-3.5-Financial
├── medical_dataset/     # Dataset pour fine-tuning médical expérimental
└── scripts/             # Scripts d'entraînement et de tests
```

## Description des dossiers

| Dossier            | Rôle                                                  |
|--------------------|-------------------------------------------------------|
| `tritton_server/`  | Configuration du serveur d'inférence Triton            |
| `models/`          | Modèle Phi-3.5-Financial                              |
| `medical_dataset/` | Dataset pour le fine-tuning médical expérimental       |
| `scripts/`         | Scripts d'entraînement et de tests                     |
